# Запуск на ESP32-S3 + MAX30102 через Thonny

Пошаговая инструкция: от пустой платы до частоты дыхания на экране.

> Прошивка проверена на программной имитации датчика (`tests/test_firmware.py`),
> но на реальной плате авторами репозитория ещё не запускалась. Если на
> каком-то шаге результат отличается от описанного, смотрите раздел
> «Если что-то не работает» в конце.

## Что понадобится

- Плата ESP32-S3-WROOM-1, модуль MAX30102, макетная плата, 4 провода DuPont
- USB-кабель **с передачей данных** (кабели «только зарядка» не подойдут)
- Компьютер с [Thonny](https://thonny.org) и Python 3.9+

## Шаг 1. Соберите схему

Плата при сборке должна быть отключена от USB.

| MAX30102 | ESP32-S3 |
|----------|----------|
| VIN | 3V3 |
| GND | GND |
| SDA | GPIO 8 |
| SCL | GPIO 9 |
| INT | не подключать |

Питание только от **3V3**, не от 5V. Схема: `hardware/wiring_diagram/wiring.svg`.

## Шаг 2. Установите MicroPython на плату

Thonny работает с платой через MicroPython, поэтому сначала его нужно
записать на ESP32-S3. Это делается один раз.

1. Подключите плату к компьютеру. Если на плате два разъёма USB, возьмите
   тот, что подписан **COM** или **UART**; если порт не появится, попробуйте
   второй.
2. Откройте Thonny → меню **Thonny → Settings…** (на Windows: **Tools →
   Options…**) → вкладка **Interpreter**.
3. В верхнем списке выберите **MicroPython (ESP32)**.
4. Внизу справа нажмите ссылку **Install or update MicroPython (esptool)**.
5. В открывшемся окне:
   - **Target port** — порт вашей платы;
   - **MicroPython family** — `ESP32-S3`;
   - **variant** — `Espressif • ESP32-S3` (если у модуля 4 МБ флеш-памяти,
     выберите вариант с `FLASH_4M`);
   - **version** — последняя из списка.
6. Нажмите **Install** и дождитесь надписи **Done**.
   Если установка не начинается: зажмите кнопку **BOOT**, коротко нажмите
   **RESET** (она же RST/EN), отпустите **BOOT** и нажмите **Install** снова.
7. Закройте окно установки, нажмите **RESET** на плате.
8. В окне Interpreter в поле **Port** выберите порт платы → **OK**.

Проверка: в нижней панели **Shell** появится строка вида
`MicroPython v1.xx … ESP32S3` и приглашение `>>>`. Если его нет, нажмите
красную кнопку **Stop** на панели инструментов.

## Шаг 3. Загрузите файлы прошивки

Файлы лежат в папке `hardware/firmware/micropython/` репозитория.

1. Включите панель файлов: **View → Files**. Сверху — файлы компьютера,
   снизу — файлы платы (**MicroPython device**).
2. В верхней части перейдите в папку `hardware/firmware/micropython`.
3. Правой кнопкой по файлу → **Upload to /**. Загрузите по очереди:
   - `max30102.py` — драйвер датчика;
   - `check_sensor.py` — проверка подключения;
   - `plot_pulse.py` — просмотр пульса на графике.

`main.py` пока **не загружайте**: он запускается автоматически при включении
платы, а сначала нужно убедиться, что датчик работает.

## Шаг 4. Проверьте датчик

1. В нижней части панели Files дважды щёлкните `check_sensor.py`.
2. Положите подушечку пальца на датчик: без нажима, неподвижно.
3. Нажмите зелёную кнопку **Run** (F5).

Ожидаемый вывод:

```
I2C devices found: ['0x57']
Part ID correct (MAX30102): True
Put a fingertip on the sensor. Measuring for 5 seconds...
Samples: 500  -> 100.0 per second (expected about 100)
Samples lost in FIFO: 0
IR level: min 115000, max 121000
OK: level looks usable.
```

Числа будут другими; важно, что найден адрес `0x57`, частота около 100 в
секунду (отклонение в несколько процентов нормально, программа на компьютере
измеряет точное значение сама) и уровень не равен 262143.

## Шаг 5. Посмотрите пульс на графике

1. **View → Plotter**.
2. Откройте `plot_pulse.py` с платы и нажмите **Run**.
3. Палец на датчике, не двигайтесь 10–15 секунд.

На графике должны идти регулярные волны — по одной на удар сердца.
Остановить: красная кнопка **Stop**.

Если волны слишком мелкие или график «упирается» в потолок, измените
`LED_CURRENT` в `main.py` (шаг 6): больше — сильнее сигнал, меньше — если
значения достигают 262143.

## Шаг 6. Загрузите основную программу

1. Загрузите `main.py` на плату (**Upload to /**).
2. Нажмите **RESET** на плате (или в Shell: Ctrl+D).

В Shell пойдёт поток данных, около 100 строк в секунду:

```
# ppg_streamer-micropython 1.0 | ESP32-S3 + MAX30102
# fs_nominal_hz=100 led_current_reg=0x1F
sample_index,device_us,ir,red,marker
0,20114,118211,95310,0
1,20114,118205,95301,0
```

Нажмите кнопку **BOOT** на плате: в одной из строк последний столбец станет
`1`. Этой кнопкой отмечается каждый вдох при записи.

Остановить поток: кнопка **Stop**.

## Шаг 7. Подготовьте программу анализа на компьютере

В терминале (не в Thonny), в папке репозитория:

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

```bash
pip install -e ".[dev]"
```

На Windows вместо второй команды: `.venv\Scripts\activate`.

Проверка без платы, на тестовом сигнале:

```bash
python scripts/run_estimation.py data/sample/SYNTHETIC_rr12.csv --reference markers
```

Должно получиться `RESPIRATORY RATE … 12.0 breaths/min`.

## Шаг 8. Запишите измерение

Порт может использовать только одна программа, поэтому:

1. **Закройте Thonny.**
2. Нажмите **RESET** на плате, чтобы `main.py` запустился заново.
3. Найдите порт:

   ```bash
   python scripts/record_serial.py --list
   ```

   На macOS он выглядит как `/dev/cu.usbmodem…` или `/dev/cu.usbserial…`,
   на Windows — `COM5` и т. п.
4. Сядьте спокойно, положите палец на датчик. Помощник смотрит на вашу
   грудную клетку и нажимает **BOOT** в начале каждого вдоха.
5. Запустите запись на 3 минуты (подставьте свой порт):

   ```bash
   python scripts/record_serial.py --port /dev/cu.usbmodem1101 --duration 180 --participant P01 --session S1 --condition rest --analyze
   ```

После записи программа сразу покажет результат:

```
Recording : data/raw/P01_S1_rest.csv  (180.0 s, fs = 99.31 Hz)
Pulses    : 214 detected, heart rate 71.4 bpm
Windows   : 17 of 19 accepted
RESPIRATORY RATE (median of accepted windows): 14.2 breaths/min [range 13.6-15.1]
Reference (button marker): 14.5 breaths/min
```

(Числа в примере условные.) Графики всех этапов обработки сохраняются в
`results/runs/P01_S1_rest/figures/`.

Если вместо числа выведено `STATUS: LOW QUALITY` или `INSUFFICIENT DATA` —
это штатное поведение: сигнал недостаточно хорош, причина указана рядом.
Повторите запись, держа палец неподвижно.

## Шаг 9. Серия измерений и статистика

Условия, количество повторов и правила описаны в
`docs/experiment_protocol.md`. Когда записей несколько, перечислите их в
`data/manifest.csv` (образец — `data/sample/manifest.csv`) и выполните:

```bash
python scripts/run_evaluation.py data/manifest.csv --outdir results/study --recording-figures
```

Отчёт с MAE, смещением, корреляцией и графиком Бланда–Альтмана появится в
`results/study/report.md`.

## Если что-то не работает

| Что видно | Причина и что делать |
|-----------|----------------------|
| В Thonny нет порта платы | Кабель без данных или другой разъём USB на плате. Смените кабель/разъём |
| Установка MicroPython не идёт | Введите плату в режим загрузки: зажать BOOT → нажать RESET → отпустить BOOT |
| `I2C devices found: []` | Датчик не отвечает: проверьте 4 провода, питание от 3V3, плотность контактов в макетной плате; SDA и SCL могли быть перепутаны |
| Найден адрес, отличный от `0x57` | Это не MAX30102 (у MAX30100 тоже 0x57, но другой Part ID — программа сообщит `False`) |
| `ImportError: no module named 'max30102'` | Файл `max30102.py` не загружен на плату (шаг 3) |
| `IR level` меньше 10000 | Палец не на датчике, либо увеличьте `LED_CURRENT` (например `0x3F`) |
| `IR level` = 262143 | Насыщение: уменьшите `LED_CURRENT` (например `0x10`), прикройте датчик от яркого света |
| Сигнал есть в столбце `red`, а в `ir` слабый | На части модулей каналы перепутаны. Добавьте к командам `--channel red` |
| `# WARN fifo_overflow` в потоке | Плата не успела забрать данные. Редкие сообщения допустимы (потеря учитывается); при частых уменьшите `POLL_MS` |
| `cannot open serial port` при записи | Порт занят: закройте Thonny и другие мониторы порта |
| `no valid samples received` | `main.py` не запущен: нажмите RESET на плате и повторите |
| Thonny не может подключиться, потому что идёт поток | Нажмите **Stop** один-два раза; `main.py` прервётся и появится `>>>` |
| Нужны другие контакты | Измените `PIN_SDA`, `PIN_SCL`, `PIN_BUTTON` в начале `main.py` и `check_sensor.py` |

## Что есть на плате после установки

| Файл | Назначение |
|------|------------|
| `max30102.py` | Драйвер датчика: настройка 100 Гц / 18 бит, чтение FIFO |
| `main.py` | Основная программа: непрерывная передача сырых данных на компьютер |
| `check_sensor.py` | Проверка подключения, частоты и уровня сигнала |
| `plot_pulse.py` | Просмотр пульсовой волны в Plotter |

Вся обработка сигнала выполняется на компьютере; плата только передаёт
немодифицированные отсчёты.
