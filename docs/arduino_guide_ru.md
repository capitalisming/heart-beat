# Запуск на ESP32-S3 + MAX30102 в Arduino IDE

Пошагово: от сборки схемы до частоты дыхания на экране компьютера. Скетч
показывает на OLED-дисплее «монитор сердца» и передаёт данные на компьютер.

> Скетч `arduino_monitor.ino` проверен так: вызовы библиотек сверены с их
> заголовочными файлами, детектор пульса скомпилирован и протестирован на
> компьютере, а формат данных сверен с программой записи. Отдельно как есть
> для ESP32 он авторами репозитория не компилировался. Если IDE выдаст ошибку,
> пришлите её текст целиком.

## Что понадобится

- Плата с ESP32-S3, модуль MAX30102, макетная плата, провода DuPont
- OLED 0.96" на SSD1306, 128×64, 4 контакта (I2C), по желанию
- USB-кабель **с передачей данных**
- [Arduino IDE 2.x](https://www.arduino.cc/en/software) и Python 3.9+ (для анализа)

## Шаг 1. Схема

Собирайте при отключённой от USB плате.

| MAX30102 | ESP32-S3 |
|----------|----------|
| VIN | 3V3 (не 5V) |
| GND | GND |
| SDA | GPIO 8 |
| SCL | GPIO 9 |
| INT | не подключать |

OLED подключается **параллельно** датчику, к тем же двум линиям I2C. Датчик
отвечает по адресу 0x57, дисплей по 0x3C, поэтому они не мешают друг другу:

| OLED | ESP32-S3 |
|------|----------|
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO 8 (туда же, куда SDA датчика) |
| SCL | GPIO 9 (туда же, куда SCL датчика) |

На макетной плате: 3V3 и GND на шины питания, SDA и SCL по одному ряду, куда
втыкаются оба модуля. Порядок контактов на дисплеях у разных продавцов разный
(GND-VCC-SCL-SDA или VCC-GND-SCL-SDA): читайте надписи на плате. Схема:
`hardware/wiring_diagram/wiring.svg`.

Если у вашей платы I2C на других контактах, поменяйте `PIN_I2C_SDA` и
`PIN_I2C_SCL` в начале скетча.

## Шаг 2. Поддержка платы ESP32 в Arduino IDE (один раз)

1. **File → Preferences** (на macOS **Arduino IDE → Settings**), поле
   **Additional boards manager URLs**: добавьте
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. **Tools → Board → Boards Manager…**, найдите **esp32 by Espressif Systems**,
   нажмите **Install**.
3. **Tools → Board**: выберите свою плату. Для типовой платы с ESP32-S3
   подойдёт **ESP32S3 Dev Module**; если в списке есть ваша точная плата
   (например Fri3d Badge 2024), выбирайте её.

## Шаг 3. Библиотеки

**Sketch → Include Library → Manage Libraries…**, найти и установить:

1. **SparkFun MAX3010x Pulse and Proximity Sensor Library**
2. **Adafruit SSD1306**
3. **Adafruit GFX Library** (IDE предложит поставить её вместе с SSD1306:
   нажмите **Install all**)

## Шаг 4. Загрузка скетча

1. **File → Open…** → `hardware/firmware/arduino_monitor/arduino_monitor.ino`.
   Рядом должен лежать `BeatDetector.h`, он откроется второй вкладкой.
2. **Tools → Port**: выберите порт платы.
3. Если после загрузки в Serial Monitor пусто, включите **Tools → USB CDC On
   Boot → Enabled** и загрузите заново (нужно платам с нативным USB).
4. Нажмите **Upload** (стрелка →). Если загрузка не начинается: зажмите
   **BOOT**, нажмите **RESET**, отпустите **BOOT**.
5. **Tools → Serial Monitor**, скорость **115200**.

## Шаг 5. Проверка

Положите подушечку пальца на датчик без сильного нажима и не двигайтесь.

**На экране OLED** слева сердечко, оно увеличивается при каждом ударе; рядом
крупные цифры пульса и подпись `BPM`; справа статус (`OK` — сигнал хороший,
`WEAK` — слабый, `---` — пальца нет); внизу бегущая кривая пульса. Пока пальца
нет, написано «Put finger on sensor». Число появляется через 5–8 секунд после
того, как палец лёг на датчик.

**В Serial Monitor** (режим по умолчанию) идёт CSV, 100 строк в секунду, плюс
раз в секунду строка `# HR bpm=72 finger=1 pulse_height=310`:

```
# arduino_monitor 1.0 | ESP32-S3 + MAX30102
# fs_nominal_hz=100 led_current_reg=0x1F oled=yes
sample_index,device_us,ir,red,marker
3323,176868651,52825,58362,0
```

| Столбец | Значение |
|---------|----------|
| `sample_index` | номер отсчёта, идёт подряд (пропуск означает потерю данных) |
| `device_us` | время платы в микросекундах |
| `ir`, `red` | сырой сигнал двух светодиодов |
| `marker` | 1 после нажатия кнопки BOOT (отметка вдоха) |

При хорошем контакте `ir` ритмично колеблется на сотни отсчётов. Если он меняется
всего на 10–20 из 50 000, пульсовой волны нет: прижмите палец плотнее или
увеличьте `LED_CURRENT`.

### Читаемый вывод значений

Чтобы значения были подписаны, измените в начале скетча строку
`#define SERIAL_MODE 0`:

| Значение | Вывод |
|----------|-------|
| `0` | CSV для записи (по умолчанию) |
| `1` | `IR=52822 RED=58361 PULSE=-12 BPM=72 FINGER=yes MARK=0`, 10 строк в секунду |
| `2` | `Pulse:-12,BPM:72`: для **Tools → Serial Plotter** (график пульса) |

Подписи: `IR` и `RED` — сырой сигнал светодиодов, `PULSE` — очищенная пульсовая
волна (удар направлен вверх), `BPM` — пульс, `FINGER` — виден ли палец, `MARK` —
нажата ли кнопка. Для записи измерений верните режим 0: программа записи
понимает только его.

### Настройка под ваш датчик

| Что | Где в скетче | Когда менять |
|-----|--------------|--------------|
| `FINGER_ON`, `FINGER_OFF` | блок settings | Если на экране «Put finger» при пальце или пульс не пропадает без пальца. Включите режим 1, посмотрите `IR` без пальца и с пальцем, поставьте пороги между этими значениями |
| `LED_CURRENT` | блок settings | `WEAK` — увеличьте (например `0x3F`); `IR` упирается в 262143 — уменьшите (`0x10`) |
| `OLED_ADDRESS` | блок settings | Дисплей не найден: попробуйте `0x3D` |
| `PIN_I2C_SDA`, `PIN_I2C_SCL`, `PIN_MARKER` | блок settings | Другая плата или другая разводка |

Пульс на экране считает упрощённый детектор (`BeatDetector.h`), он нужен только
для показа. Научный анализ работает по сырым данным.

## Шаг 6. Программа анализа на компьютере (Windows)

1. Установите **Python 3.12 или 3.13**: <https://www.python.org/downloads/windows/>.
   На первом экране установщика обязательно поставьте галочку
   **Add python.exe to PATH**.
2. Скачайте проект: на странице GitHub нажмите **Code → Download ZIP** и
   распакуйте архив (или `git clone https://github.com/capitalisming/heart-beat.git`).
3. Откройте папку проекта и **дважды щёлкните `install_windows.bat`**.

Установщик создаёт окружение `.venv`, ставит пакеты (нужен интернет), запускает
тесты, показывает пробный запуск на тестовом сигнале и список портов.
В конце тестов будет `passed` и несколько `skipped`: тесты C++-детектора
пропускаются, потому что на Windows нет компилятора, это нормально. Установщик
можно запускать повторно.

Установщик написан для Windows, но авторами на Windows не запускался. Если он
остановился, он пишет причину. Те же действия вручную (PowerShell или cmd, в
папке проекта):

```powershell
py -3 -m venv .venv
```

```powershell
.\.venv\Scripts\python -m pip install -e ".[dev]"
```

Дальше все команды запускаются через `ppg.bat`, активировать окружение не
нужно: в cmd пишите `ppg scripts\...`, в PowerShell `.\ppg scripts\...`.

Проверка без платы (должно выйти 12.0 breaths/min):

```bash
ppg scripts\run_estimation.py data\sample\SYNTHETIC_rr12.csv --reference markers
```

macOS и Linux: `python3 -m venv .venv`, `source .venv/bin/activate`,
`pip install -e ".[dev]"`, затем `python scripts/...` вместо `ppg scripts\...`.

## Шаг 7. Запись измерения

Порт может использовать только одна программа, поэтому:

1. **Закройте Serial Monitor и Serial Plotter** в Arduino IDE.
2. Убедитесь, что `SERIAL_MODE` равен 0 (шаг 5).
3. Найдите порт одним из способов:
   - в Arduino IDE: **Tools → Port** (например `COM5`);
   - в Windows: **Диспетчер устройств → Порты (COM и LPT)**;
   - командой:

   ```bash
   ppg scripts\record_serial.py --list
   ```

   Плата с ESP32-S3 обычно определяется как COM-порт без драйверов. Если у платы
   отдельный USB-чип (CH340, CP210x) и порта нет, нужен драйвер этого чипа от
   продавца платы. На macOS порт выглядит как `/dev/cu.usbmodem…`, на Linux как
   `/dev/ttyACM0`.
4. Сядьте спокойно, положите палец на датчик. Помощник смотрит на вашу грудную
   клетку и нажимает **BOOT** в начале каждого вдоха.
5. Запустите запись на 3 минуты (подставьте свой порт):

   ```bash
   ppg scripts\record_serial.py --port COM5 --duration 180 --participant P01 --session S1 --condition rest --analyze
   ```

   Открытие порта может перезагрузить плату; запись начнётся с первого
   принятого отсчёта.

После записи программа сразу покажет результат (числа в примере условные):

```
Recording : data\raw\P01_S1_rest.csv  (180.0 s, fs = 99.31 Hz)
Pulses    : 214 detected, heart rate 71.4 bpm
Windows   : 17 of 19 accepted
RESPIRATORY RATE (median of accepted windows): 14.2 breaths/min [range 13.6-15.1]
Reference (button marker): 14.5 breaths/min
```

Графики всех этапов сохраняются в `results\runs\P01_S1_rest\figures\`.

Если вместо числа выведено `STATUS: LOW QUALITY` или `INSUFFICIENT DATA`, это
штатное поведение: сигнал недостаточно хорош, причина указана рядом. Повторите
запись, держа палец неподвижно.

## Шаг 8. Серия измерений и статистика

Условия, число повторов и правила описаны в `docs/experiment_protocol.md`.
Когда записей несколько, перечислите их в `data/manifest.csv` (образец:
`data/sample/manifest.csv`) и выполните:

```bash
ppg scripts\run_evaluation.py data\manifest.csv --outdir results\study --recording-figures
```

Отчёт с MAE, смещением, корреляцией и графиком Бланда–Альтмана появится в
`results\study\report.md`.

## Если что-то не работает

| Что видно | Что делать |
|-----------|------------|
| Ошибка компиляции про `Adafruit_SSD1306.h`, `Adafruit_GFX.h` или `MAX30105.h` | Не установлена библиотека (шаг 3) |
| Другая ошибка компиляции | Пришлите её текст целиком |
| Плата не видна в **Tools → Port** | Кабель без данных или другой разъём USB на плате; режим загрузки: BOOT + RESET |
| Serial Monitor пустой | Скорость 115200; включите **USB CDC On Boot**; нажмите RESET |
| `# ERROR MAX30102 not found` | Проверьте 4 провода датчика и питание от 3V3; SDA и SCL могли быть перепутаны |
| `# WARN OLED not found` | Проверьте VCC/GND/SDA/SCL дисплея (порядок контактов бывает разный) и адрес (`OLED_ADDRESS` 0x3C или 0x3D). Запись и вывод работают и без дисплея |
| Экран чёрный | Питание дисплея только от 3V3; проверьте адрес |
| `IR` равен 262143 | Насыщение: уменьшите `LED_CURRENT`, прикройте датчик от яркого света |
| Вместо пульса `WEAK` | Слабый сигнал: прижмите палец аккуратнее, увеличьте `LED_CURRENT`; пульсовая волна меньше 15 отсчётов не считается пульсом |
| Сигнал есть в `red`, а в `ir` слабый | На части модулей каналы перепутаны: добавьте к командам `--channel red` |
| `# WARN fifo_overflow` часто | Плата не успевает забирать данные: увеличьте `DRAW_INTERVAL_MS` (реже обновлять экран) |
| `cannot open serial port` при записи | Порт занят: закройте Serial Monitor и Serial Plotter. Проверьте номер `COM` в Диспетчере устройств |
| `install_windows.bat`: «Python was not found» | Python не установлен или без галочки **Add python.exe to PATH**: переустановите и отметьте её |
| В PowerShell `ppg` не находится | Пишите `.\ppg` (с точкой и обратной косой чертой) или запускайте из cmd |
| `no valid samples received` | Нажмите RESET на плате и повторите; проверьте, что `SERIAL_MODE` равен 0 |
| Пульс на экране заметно отличается от настоящего | Это упрощённый детектор для показа: двигайте пальцем меньше, подождите 10 секунд; научные результаты считаются по сырым данным |
