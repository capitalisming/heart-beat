# Прошивка через Arduino IDE (вместо Thonny)

Тот же «монитор сердца» с OLED-дисплеем, но скетчем для Arduino IDE.
Схема подключения — как в [thonny_guide_ru.md](thonny_guide_ru.md), шаг 1
(датчик и OLED параллельно на GPIO 8 и 9, питание от 3V3).

> Скетч не компилировался для ESP32 и не запускался на плате авторами
> репозитория: вызовы библиотек сверены с их заголовочными файлами, а
> детектор пульса скомпилирован и проверен на компьютере. Если Arduino IDE
> выдаст ошибку компиляции, пришлите её текст целиком.

## 1. Библиотеки

**Sketch → Include Library → Manage Libraries…** (или значок книг слева),
найти и установить:

1. **SparkFun MAX3010x Pulse and Proximity Sensor Library**
2. **Adafruit SSD1306**
3. **Adafruit GFX Library** (при установке SSD1306 IDE предложит поставить её
   вместе — согласитесь, **Install all**)

Плата: **Tools → Board → esp32 → ESP32S3 Dev Module** (пакет
*esp32 by Espressif Systems* в Boards Manager). Если у вас другая плата,
выберите её; контакты I2C можно поменять в начале скетча.

## 2. Загрузка

1. Откройте `hardware/firmware/arduino_monitor/arduino_monitor.ino`.
   Файл `BeatDetector.h` должен лежать рядом (он откроется второй вкладкой).
2. Выберите порт: **Tools → Port**.
3. Если у платы нативный USB и Serial Monitor молчит, включите
   **Tools → USB CDC On Boot → Enabled** и загрузите заново.
4. Нажмите **Upload** (стрелка →). Если загрузка не начинается: зажмите
   **BOOT**, нажмите **RESET**, отпустите **BOOT**.
5. Откройте **Tools → Serial Monitor**, скорость **115200**.

На экране OLED появится монитор сердца (сердечко, пульс, бегущая кривая), а в
Serial Monitor — данные.

## 3. Что в Serial Monitor

По умолчанию (`SERIAL_MODE 0`) это CSV для записи:

```
sample_index,device_us,ir,red,marker
3323,176868651,52825,58362,0
```

| Столбец | Значение |
|---------|----------|
| `sample_index` | номер отсчёта, идёт подряд (пропуск = потеря данных) |
| `device_us` | время платы, мкс |
| `ir`, `red` | сырой сигнал двух светодиодов |
| `marker` | 1 после нажатия кнопки BOOT (отметка вдоха) |

Раз в секунду добавляется строка `# HR bpm=72 finger=1 pulse_height=310`:
пульс, виден ли палец, размах пульсовой волны.

Чтобы выводить значения **с подписями**, в начале скетча измените строку
`#define SERIAL_MODE 0`:

| Значение | Вывод |
|----------|-------|
| `0` | CSV для записи (по умолчанию) |
| `1` | `IR=52822 RED=58361 PULSE=-12 BPM=72 FINGER=yes MARK=0`, 10 строк/с |
| `2` | `Pulse:-12,BPM:72` — для **Tools → Serial Plotter** (кривая пульса) |

Для записи измерений нужен режим 0: `scripts/record_serial.py` понимает
только его. Перед записью **закройте Serial Monitor и Serial Plotter**:
порт может использовать только одна программа.

## 4. Настройка под ваш датчик

| Что | Где в скетче | Когда менять |
|-----|--------------|--------------|
| `FINGER_ON`, `FINGER_OFF` | блок settings | Если на экране «Put finger» при пальце или пульс не пропадает без пальца. Включите режим 1, посмотрите `IR` без пальца и с пальцем, поставьте пороги между ними |
| `LED_CURRENT` | блок settings | Пульсовая волна слабая (`WEAK`) — увеличьте (например `0x3F`); `IR` упирается в 262143 — уменьшите (`0x10`) |
| `OLED_ADDRESS` | блок settings | Дисплей не найден: попробуйте `0x3D` |
| `PIN_I2C_SDA`, `PIN_I2C_SCL`, `PIN_MARKER` | блок settings | Другая плата или другая разводка |

## 5. Что вы видели на скриншоте

Строки вида `3334,176979269,52822,58361,0` — это режим 0. В вашем
фрагменте `ir` меняется всего на ~10 отсчётов из 52 000: пульсовой волны в нём
нет. Положите палец на датчик плотно, но без сильного нажима; на хорошем
контакте `ir` ритмично колеблется на сотни отсчётов, а на экране появляется
кривая и число.

## 6. Если что-то не работает

| Что видно | Что делать |
|-----------|------------|
| Ошибки компиляции про `Adafruit_SSD1306.h` или `MAX30105.h` | Не установлена библиотека (раздел 1) |
| `# WARN OLED not found` | Проверьте VCC/GND/SDA/SCL дисплея и адрес |
| `# ERROR MAX30102 not found` | Проверьте 4 провода датчика и питание 3V3 |
| `# WARN fifo_overflow` часто | Плата не успевает забирать данные: отключите вывод в режиме 0 или уменьшите частоту обновления экрана (`DRAW_INTERVAL_MS` больше) |
| Экран чёрный | Питание дисплея только от 3V3; проверьте адрес |
